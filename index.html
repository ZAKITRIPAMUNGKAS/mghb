XLOOKUP: Rekonsiliasi NIK / No. Rekening Cabang
Excel Modern
Alternatif modern pengganti VLOOKUP yang lebih aman dan fleksibel. Mencari data nasabah atau pimpinan cabang tanpa terpengaruh posisi kolom kiri/kanan serta menangani *not found* secara elegan. 
=XLOOKUP(A2; 'Master_Cabang'!A:A; 'Master_Cabang'!C:C; "Data Tidak Ditemukan"; 0)
💡 Kasus: Padankan kode cabang pada sheet laporan harian dengan nama outlet di master data.
SUMIFS: Agregasi Saldo DPK Berdasarkan Kriteria Wilayah
Excel / Calc
Menjumlahkan total saldo DPK atau realisasi volume transaksi hanya untuk cabang yang memenuhi beberapa kriteria (misal: Wilayah tertentu dan status cabang Aktif). 
=SUMIFS(D:D; B:B; "Wilayah 03"; C:C; "Aktif")
💡 Kolom D = Saldo DPK, Kolom B = Nama Wilayah, Kolom C = Status Cabang.
Formula Rasio CASA (Current Account Saving Account)
Metrik Inti BNI
Menghitung porsi dana murah (Giro + Tabungan) terhadap total DPK. Metrik kunci performa perbankan yang dipantau divisi SSE setiap minggu. 
=IF(D2>0; (B2 + C2) / D2; 0)
💡 B2 = Giro, C2 = Tabungan, D2 = Total DPK. Format sel sebagai Percentage (0.00%).
Formula Pertumbuhan Penjualan MoM & YoY
Analisis Kinerja
Menghitung delta laju pertumbuhan volume penjualan atau saldo DPK antar bulan (*Month-over-Month*) dengan penanganan pembagian nol (*Safe Division*). 
=IF(B2>0; (C2 - B2) / B2; 0)
💡 B2 = Realisasi Bulan Lalu, C2 = Realisasi Bulan Ini. Format sel sebagai Percentage.
INDEX + MATCH: Pencarian Bersyarat Multi-Kriteria
Excel Lanjutan
Mencari target atau realisasi berdasarkan 2 parameter sekaligus (misal: Nama Cabang DAN Jenis Produk Tabungan Bisnis). 
=INDEX(E2:E100; MATCH(1; (A2:A100=G2) * (B2:B100=H2); 0))
💡 G2 = Target Cabang, H2 = Produk. Tekan Ctrl+Shift+Enter jika di Excel versi lama.
SQL: Top 10 Cabang Rasio CASA Tertinggi
Query DWH
Mengagregasi saldo harian dari data warehouse bank untuk memetakan kantor cabang dengan efisiensi dana murah terbaik. 
SELECT 
    kode_cabang, 
    nama_cabang, 
    wilayah,
    SUM(saldo_giro + saldo_tabungan) AS total_casa,
    SUM(saldo_giro + saldo_tabungan + saldo_deposito) AS total_dpk,
    ROUND((SUM(saldo_giro + saldo_tabungan) / NULLIF(SUM(saldo_giro + saldo_tabungan + saldo_deposito), 0)) * 100, 2) AS rasio_casa_pct
FROM dwh_daily_balance
WHERE tanggal_posisi = CURRENT_DATE - INTERVAL '1 day'
GROUP BY kode_cabang, nama_cabang, wilayah
ORDER BY rasio_casa_pct DESC
LIMIT 10;
💡 NULLIF mencegah error Division by Zero jika ada cabang baru yang saldonya masih 0.
SQL: Perbandingan Realisasi Penjualan MoM per Segmen
Analitik Penjualan
Membandingkan volume pencapaian sales produk antar bulan berjalan dan bulan sebelumnya per segmentasi nasabah (Consumer, Commercial, SME). 
SELECT 
    segmentasi_nasabah,
    SUM(CASE WHEN EXTRACT(MONTH FROM tanggal_transaksi) = EXTRACT(MONTH FROM CURRENT_DATE) THEN nominal_realisasi ELSE 0 END) AS bulan_ini,
    SUM(CASE WHEN EXTRACT(MONTH FROM tanggal_transaksi) = EXTRACT(MONTH FROM CURRENT_DATE - INTERVAL '1 month') THEN nominal_realisasi ELSE 0 END) AS bulan_lalu,
    ROUND(
        ((SUM(CASE WHEN EXTRACT(MONTH FROM tanggal_transaksi) = EXTRACT(MONTH FROM CURRENT_DATE) THEN nominal_realisasi ELSE 0 END) -
          SUM(CASE WHEN EXTRACT(MONTH FROM tanggal_transaksi) = EXTRACT(MONTH FROM CURRENT_DATE - INTERVAL '1 month') THEN nominal_realisasi ELSE 0 END)) /
          NULLIF(SUM(CASE WHEN EXTRACT(MONTH FROM tanggal_transaksi) = EXTRACT(MONTH FROM CURRENT_DATE - INTERVAL '1 month') THEN nominal_realisasi ELSE 0 END), 0)
        ) * 100, 2
    ) AS growth_mom_pct
FROM sales_pipeline_transaksi
GROUP BY segmentasi_nasabah;
💡 Membantu evaluasi apakah performa penjualan ritel/korporat tumbuh positif.
SQL: Deteksi Calon Nasabah (Leads) Stagnan di Pipeline
Monitoring Funnel
Menemukan daftar prospek nasabah yang mandek lebih dari 14 hari di satu tahapan pipeline penjualan untuk ditindaklanjuti Relationship Manager (RM). 
SELECT 
    lead_id,
    nama_nasabah,
    produk_ditawarkan,
    nama_rm_sales,
    tahap_pipeline,
    CURRENT_DATE - tanggal_update_terakhir AS hari_stagnan
FROM leads_pipeline
WHERE tahap_pipeline NOT IN ('CLOSING_WON', 'CLOSING_LOST')
  AND (CURRENT_DATE - tanggal_update_terakhir) > 14
ORDER BY hari_stagnan DESC;
💡 Disajikan dalam weekly catchup SSE sebagai bahan evaluasi tindak lanjut RM cabang.
Python: Otomasi Menggabungkan Puluhan File Excel Cabang
Efisiensi IT
Menghemat jam kerja manual dengan membaca dan menyatukan seluruh berkas `.xlsx` laporan dari puluhan cabang dalam satu folder menjadi satu master dataset. 
import os
import glob
import pandas as pd

# Cari semua file laporan cabang di folder data
file_paths = glob.glob('./data_cabang/*.xlsx')
df_list = []

for f in file_paths:
    df = pd.read_excel(f)
    df['nama_file_asal'] = os.path.basename(f)
    df_list.append(df)

# Satukan seluruh data ke satu tabel master
master_df = pd.concat(df_list, ignore_index=True)
master_df.to_excel('Master_Rekap_SSE_Combined.xlsx', index=False)
print(f"Berhasil menggabungkan {len(file_paths)} berkas cabang!")
💡 Solusi instan jika tiap Jumat menerima puluhan spreadsheet cabang terpisah.
Python: Pembersihan Data (Spasi, Format Tanggal, & Nilai Kosong)
Data Cleansing
Membersihkan spasi tersembunyi (*trailing spaces*), menstandarisasi kolom tanggal ke format ISO `YYYY-MM-DD`, mengisi nilai null, dan menghapus data duplikat. 
import pandas as pd

df = pd.read_excel('raw_sales_data.xlsx')

# 1. Bersihkan spasi depan/belakang pada semua kolom teks
str_cols = df.select_dtypes(include=['object']).columns
df[str_cols] = df[str_cols].apply(lambda s: s.str.strip())

# 2. Standarisasi format tanggal
df['tgl_transaksi'] = pd.to_datetime(df['tgl_transaksi'], errors='coerce').dt.strftime('%Y-%m-%d')

# 3. Ganti nilai kosong (NaN) pada kolom nominal dengan 0
df['nominal_realisasi'] = df['nominal_realisasi'].fillna(0)

# 4. Buang transaksi duplikat berdasarkan ID unik
df = df.drop_duplicates(subset=['id_transaksi'])

df.to_csv('clean_sales_data.csv', index=False)
print("Data cleansing selesai! Data siap dianalisis.")
💡 Mencegah formula Excel error karena spasi tak terlihat di nama nasabah / ID rekening.
Python: Deteksi Anomali / Lonjakan Saldo Ekstrem (IQR)
Audit Data
Menggunakan metode statistik *Interquartile Range (IQR)* untuk mendeteksi transaksi atau saldo nasabah bernilai anomali tinggi yang perlu dikonfirmasi. 
import pandas as pd

df = pd.read_excel('laporan_saldo_harian.xlsx')

q1 = df['saldo_total'].quantile(0.25)
q3 = df['saldo_total'].quantile(0.75)
iqr = q3 - q1

# Batas atas anomali saldo
upper_bound = q3 + (1.5 * iqr)
outliers = df[df['saldo_total'] > upper_bound]

print(f"Ditemukan {len(outliers)} data saldo anomali:")
print(outliers[['kode_cabang', 'no_rekening', 'saldo_total']].head())
💡 Membantu divisi SSE mengidentifikasi pergerakan dana besar nasabah korporat.
